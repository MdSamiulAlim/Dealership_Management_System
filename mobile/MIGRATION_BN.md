# Flutter অ্যাপে যাওয়ার নিয়ম

- প্রথমে পুরোনো অ্যাপে সব ডিভাইসে Sync শেষ করুন। অপেক্ষমাণ কাজের সংখ্যা শূন্য আছে কি না দেখুন।
- Settings & Backup থেকে encrypted device backup Export করে রাখুন। যে পাসওয়ার্ডে ব্যাকআপ করেছেন, সেটি প্রয়োজন হবে।
- পুরোনো অ্যাপ uninstall করবেন না বা data clear করবেন না। নতুন APK দিয়ে Update করুন।
- একই User ID ও Password দিয়ে অনলাইনে লগইন করলে সার্ভারের সব হিসাব আসবে।
- পুরোনো অ্যাপের শুধু ডিভাইসে থাকা কাজ সরাসরি Flutter storage-এ আসে না। প্রয়োজন হলে নতুন অ্যাপে Settings & backup থেকে পুরোনো encrypted JSON ব্যাকআপ Import করুন। অপেক্ষমাণ কাজের ID অক্ষুণ্ণ থাকে।
- নতুন অ্যাপে Offline ব্যবহার করতে প্রথমবার অনলাইনে লগইন করুন। এরপর login screen-এ “ইন্টারনেট ছাড়া খুলুন” দিয়ে পাসওয়ার্ড ব্যবহার করতে পারবেন।
- একই অ্যাকাউন্ট একাধিক ডিভাইসে ব্যবহার করা যাবে। ইন্টারনেট সংযোগ পেলে প্রতিটি ডিভাইস সার্ভারের সঙ্গে Sync হবে।
- Sync-এ সমস্যা হলে নতুন payment হিসেবে আবার সেভ করবেন না। অপেক্ষমাণ কাজের তালিকা থেকে Sync / Retry করুন।
- শুধুমাত্র অ্যাডমিন সব হিসাব Reset করতে পারবেন। পণ্যের তালিকা ও দর অক্ষুণ্ণ থাকবে।

এই সংস্করণে সব মোবাইল screen Flutter-এ তৈরি। পুরোনো root Android/WebView client অবসর নিয়েছে; `mobile/android/` Flutter-এর স্বাভাবিক build runner।
