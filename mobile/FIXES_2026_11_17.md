# Percentage discount half-up rounding — released in 3.0.4

Release update: these changes are now included in the owner-requested signed
Flutter 3.0.4 (build 10) APKs in `../releases/`.

Percentage discounts now use integer hundredths of a percent and BigInt rational
arithmetic. On a 50.00 invoice, 0.57% discounts 0.29 and produces 49.71, including
the encrypted pending-invoice projection. Allocation uses the existing exact
largest-remainder rules.

The 17 shared decimal-oracle cases cover half-paisa boundaries, multi-item
allocation, zero/full discounts and the largest supported invoice. Existing
saved invoices are not rewritten: they retain only the saved discount amount,
not the original percentage. To correct one, re-enter the percentage in its
editor and save. Returned/cancelled invoice safeguards remain in force.

The previous 3.0.3 APK predates these changes. The owner-requested 3.0.4 release
now includes them; future APK rebuilds still require the owner's request.
