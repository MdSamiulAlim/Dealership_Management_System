# Record actions — released in 3.0.4

Release update: these changes are now included in the owner-requested signed
Flutter 3.0.4 (build 10) APKs in `../releases/`. The unreleased-source notes below
describe the state before that release.

- Orders, all money types and stock adjustments now have functional Edit/Delete
  actions. Stock history includes a paginated view of every adjustment.
- Customer and Sales cards expose actions directly. Invoice Delete cancels its
  stock/financial effects while retaining the original invoice history.
- Order/adjustment replacement checks the old and new stock effects; neither
  product can lose unavailable bags. Cash/Bank transfer edits update both entries
  and guard the original counterpart. Replay uses the existing durable operation ID.
- Pending records require Sync first. Linked products/customers remain protected;
  returned/cancelled invoice amounts and audit/return journals remain protected.
- Stock, transfer and order changes require confirmation; editor Back/lock/session
  protections remain active. Delivery date may remain blank on a pending order.

The previous 3.0.3 APK predates these changes. The owner-requested 3.0.4 release
now includes them; future APK rebuilds still require the owner's request.

## Blank new entries

New forms no longer initialize manual fields from hardcoded defaults or menu
presets. New Sale has blank customer/date, quantity/rate, discount/payment and
account controls. Choosing a product does not fill its price/pack weight.
Explicitly choosing a customer loads that customer's saved contact details.
New returns require an explicit restock choice and start with empty date and
quantities. Optional blank return quantities mean no return for those lines.

The owner sets the Low Stock Alert. Existing record editors retain stored values.
Product field names and order, catalog data and financial calculations are
preserved. Calculated totals, generated IDs and the live header clock remain
automatic. These changes are included in the 3.0.4 release APKs.
