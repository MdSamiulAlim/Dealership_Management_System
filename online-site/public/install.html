Android APK ডাউনলোড করুন

সংস্করণ 2.2.0 · Android 6.0 বা পরবর্তী সংস্করণ · প্রথমবার ইন্টারনেট প্রয়োজন; এরপর Offline চালু করা যাবে

  1. আগের অ্যাপ থাকলে আনইনস্টল না করে এই APK দিয়ে Update করুন।
  2. APK ডাউনলোড করে ফোনের Downloads থেকে ফাইলটি খুলুন।
  3. ইনস্টলের অনুমতি চাইলে যে ব্রাউজার থেকে ডাউনলোড করেছেন, সেটির অনুমতি দিয়ে Install চাপুন।
  4. অ্যাপ খুলে নিজের User ID ও নির্ধারিত পাসওয়ার্ড দিন।

Sales-এ একাধিক পণ্য, Discount, Partial Payment, Return, View/Edit, PDF, Print ও Share ব্যবহার করুন। Settings & Backup → Enable Offline চাপুন এবং লগইন দিন। এরপর ইন্টারনেট ছাড়াও কাজ সেভ হবে; অ্যাপ খোলা থাকলে সংযোগ ফিরে এলে স্বয়ংক্রিয় Sync হবে। Pending কাজ Sync হওয়ার আগে অ্যাপের ডেটা মুছবেন না।
